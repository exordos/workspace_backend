# Zulip План испытаний моста V1

Этот план является исполняемым шлюзом для приема поставщиком-нейтральным Workspace
Внешне-счетный лимит и его первый`zulip`В настоящее время
План регрессии Messenger; сообщения IAM, реального времени и S3
Поведение должно оставаться зеленым на протяжении всего развертывания.

Канонические Messenger ресурсы и команды провайдера живут в PostgreSQL и
Обменялась через частныйWorkspaceПровайдерAPIЭтот план должен быть выполнен .
с восстановлением и загрузкой ворот в
[`messenger_regression_test_plan.md`](messenger_regression_test_plan.md).

## Требуемая среда

- Workspace бэк-энд обновлен с его каноническими данными PostgreSQL и S3
  сохранился.
- Один независимый обновляемый узел `workspace-zulip-bridge` с заменяемым
  корневой диск и постоянный диск операционных данных.
- Специальное испытательное поле Zulip с не менее чем четырьмя пользователями, один канал с двумя
  темы, личный DM, групповой DM и файлы, подходящие для обоих направлений.
- S3-совместимое Workspace хранилище и частный Workspace Провайдер API.
- Обычный `cassi` Workspace аккаунт в видимом окне Playwright MCP.
- Все пятнадцать ресурсов разрешений внешней интеграции IAM и оба предварительно определенных
  Роли, согласованы с манифестом элемента Workspace.
  - Да .`cassi`Только вWorkspaceIAMОбычно .Workspace
  роли не должны получать эти разрешения подразумевается.

   IAM разрешения и обе не присвоенные роли.
